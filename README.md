📊 Análise de Vendas — E-commerce Olist
Análise exploratória de +110 mil pedidos reais do e-commerce brasileiro Olist utilizando Python, Pandas e Power BI.

🎯 Perguntas respondidas
* Quais estados têm maior volume de vendas?
* Quais categorias de produto têm maior ticket médio?
* Como as vendas evoluíram mês a mês entre 2016 e 2018?


🔍 Principais insights
* SP concentra quase 40% do faturamento total — R$ 5,1 Mi
* As vendas mensais cresceram mais de 20x em um ano
* Novembro registrou o maior pico — Black Friday movimentando ~R$ 1 Mi
* PCs lideram o ticket médio com R$ 1.099 por pedido


🛠️ Tecnologias utilizadas
* Python 3
* Pandas
* Power BI
* Excel
